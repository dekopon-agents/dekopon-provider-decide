# Dekopon decide provider

One Wasm component, one advisory `decide.choose` capability. Input is `{backend, model, evidence, labels, requireProbabilities}`. The two allowed pairs are `openrouter-luna` / `openai/gpt-6-luna-decisions` and `openrouter-jev` / `typesafe/jev-1.13`. Evidence is an array of 1–256 records with exactly `{tool, outcome, exitStatus?, ageMs, bytes, pinned}`: `tool` is `bash` or `none`, `outcome` is `success`, `failure` or `none`, `exitStatus` when present is a u8, age and bytes are nonnegative u64, and pinned is a boolean. Labels are 2–32 distinct strings of 1–128 ASCII letters, digits, `-`, `_` or `.`. Unknown fields, free text and URLs refuse before HTTP; no original conversation text, credentials or arbitrary notes are accepted. The operator may set `providerSettings.decide.baseUrl` (default `https://openrouter.ai`); the broker still enforces its destination grant and injects credentials. No input field sets the URL or authentication.

The adapter POSTs to `/api/alpha/decisions`, with a single keyed `decision` choice question, stable labels as criteria and evidence as state. The answer is exactly one JSON line: success `{choice, probabilities?, backend, model}` or refusal `{refused:true, backend, model}`. `model` on response is the resolved model when HTTP succeeded. A distribution is present only when returned by the native endpoint, must cover exactly the offered labels with finite values in [0,1] and total within **0.01** of 1. Missing probabilities are not fabricated. Invalid input, malformed output, unknown choice, unsupported profile, and network failures produce bounded errors. A missing or null *required* distribution produces a refusal without a choice. Jev's [OpenRouter Decisions reference](https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request), read 2026-10-16, shows optional probabilities on a choice answer and resolved model `typesafe/jev-1.13-20260917`. Luna's slug comes from IDEA-0009 research (2026-10-07); its probability support remains unverified pending a separately authorized live probe. Requests requiring probabilities on Luna refuse **before HTTP**. A missing/null required Jev distribution refuses after HTTP. No vendor refusal wire variant is assumed. A decision cannot grant permission; Cedar evaluates separately.

The single host HTTP call consumes the broker's invocation limits. There is no guest retry, independent budget, or cross-invocation allowance. The source PR does not enable any live credential, egress grant, release or RPi route. Offline fixture tests do not establish the real vendor's behavior.
