# Dekopon decide provider

One Wasm component, one advisory `decide.choose` capability. Input is `{backend, model, evidence, labels, requireProbabilities}`. The two allowed pairs are `openrouter-luna` / `openai/gpt-6-luna-decisions` and `openrouter-jev` / `typesafe/jev-1.13`. Evidence is JSON metadata (at most 16 KiB); labels are 2–32 distinct, trimmed, nonempty strings (at most 128 bytes each). Do not put secrets or original conversation text into evidence. The operator may set `providerSettings.decide.baseUrl` (default `https://openrouter.ai`); the broker still enforces its destination grant and injects credentials. No input field sets the URL or authentication.

The adapter POSTs to `/api/alpha/decisions`, with a single keyed `decision` choice question, stable labels as criteria and evidence as state. The answer is exactly one JSON line: success `{choice, probabilities?, backend, model}` or refusal `{refused:true, backend, model}`. `model` on response is the resolved model when HTTP succeeded. A distribution is present only when returned by the native endpoint, must cover exactly the offered labels with finite values in [0,1] and total within **0.01** of 1. Missing probabilities are not fabricated. Invalid input, malformed output, unknown choice, unsupported profile, and network failures produce bounded errors. A native refusal or required-but-missing distribution produces a refusal without a choice. Both allowed models document native choice probabilities ([OpenRouter Decisions reference](https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request) and [Luna catalog](https://openrouter.ai/openai/gpt-6-luna-decisions), read 2026-10-16). Neither guarantees a distribution on every individual response; missing required distributions refuse without a choice. A synthetic `cfg(test)`-only incapable profile exercises the pre-HTTP refusal without misclassifying Jev or adding a third production backend. A decision cannot grant permission; Cedar evaluates separately.

The single host HTTP call consumes the broker's invocation limits. There is no guest retry, independent budget, or cross-invocation allowance. The source PR does not enable any live credential, egress grant, release or RPi route. Offline fixture tests do not establish the real vendor's behavior.
